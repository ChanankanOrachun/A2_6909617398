What I built

เว็บไซต์นี้สร้างขึ้นเพื่อเป็นโครงสร้างเว็บไซต์หน้าเดียวสำหรับนำเสนอข้อมูลส่วนตัว และสิ่งที่ได้เรียนรู้เกี่ยวกับวิชานี้ และเป็นเว็บไซต์ Learning Portfolio

นอกจากนี้ ในขณะที่เปิดเว็บไซต์นี้ผ่านเครื่องคอมพิวเตอร์จากไฟล์ HTML จะมีเพียง Client ที่เกิดขึ้นเท่านั้น ไม่มี Server เกิดขึ้น เพราะเป็นการดึงข้อมูลไฟล์ HTML จากเครื่องมาประมวลผลโดยตรง โดยไม่ต้องส่งคำขอ(Request)ไปหา Server ตัวไหนเลย

How I built it

ขั้นตอนการสร้าง:
  1. วางโครงสร้าง (Structure): เขียนโครงสร้างของเว็บไซต์ด้วย HTML จากนั้นจัดสัดส่วนข้อมูลและใส่รูปภาพ
  2. ตกแต่ง (Decoration): ใช้ CSS ตกแต่งกำหนดฟอนต์ตัวอักษร สีตัวอักษร สีพื้นหลัง และ Layout ของเว็บไซต์
  3. ตรวจสอบ (Check): ตรวจสอบความถูกต้องและการทำงานของเว็บไซต์ไม่ให้เกิดปัญหาขึ้นเมื่อเปิดใช้งาน
เครื่องมือ:
  • Visual Studio Code: ใช้ในการเขียนโค้ดและพัฒนาเว็บไซต์
  • Search Engine: ใช้ในการค้นคว้าหาข้อมูล

Reflection

ปัญหาและความท้าทายที่พบ

การจัด Layout ให้สวยงามและการทำความเข้าใจเส้นทางของไฟล์(Relative Path) ซึ่งแก้โดยการศึกษาค้นคว้าเพิ่มและทำความเข้าใจเพิ่ม

สิ่งที่เข้าใจเกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น

ได้เข้าใจในเรื่องของเส้นทางของไฟล์(Relative Path) และโครงสร้างของเว็บไซต์มากขึ้น ทั้งยังได้โอกาสในการศึกษาค้นคว้าในเรื่อง Semantic HTML และ CSS properties เพิ่มเติมเพื่อนำมาพัฒนาเว็บไซต์อีกด้วย

สิ่งที่อยากพัฒนาและปรับปรุง

อยากพัฒนาและปรับปรุง Layout ให้สวยงามและใส่ลูกเล่นต่างๆ เพราะอยากให้เว็บไซต์มีความน่าสนใจมากขึ้น
